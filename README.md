# 粒子梦境 Particle Run · 双人版

可爱复古霓虹像素风双人在线跑酷：两名玩家通过**房间码**进入同一条赛道，同一时刻起跑，收集星尘、躲避尖刺与幻球，坠毁即出局，分数高者获胜。

原单机版（`../particle-run.html`）保留未动；本项目是其双人联机版。

## 玩法

- 空格 / 鼠标点击 / 触屏：跳跃，**长按跳更高**
- 收集星尘 +10 分，距离本身也持续计分
- 撞到尖刺或幻球即坠毁出局，另一人可继续奔跑；两人都坠毁后结算
- 每个房间最多 2 人；断线 8 秒内刷新页面可自动回到原房间续跑

## 技术方案

- 前端：单文件 HTML/CSS/JS（无构建步骤），Canvas 2D 像素霓虹渲染
- 后端：Node.js + Express（托管页面）+ Socket.IO（WebSocket 优先，必要时自动回退轮询）
- 同步设计：
  - 赛道由服务器下发的**随机种子**在两台电脑上确定性生成，保证双方赛道完全一致
  - 距离由「开始时刻 + 服务器时钟校准」解析计算，后台标签页/卡顿也不会跑偏
  - 跳跃事件（按下/松开）实时转发 + 10Hz 状态纠正包，远端角色平滑插值
  - 收集判定在服务器仲裁：同一颗星尘只计一次，杜绝重复计数

## 运行要求

- Node.js ≥ 16（建议 18/20/22）

## 本地运行

```bash
npm install
npm start            # 默认 http://localhost:3000，可用 PORT 环境变量改端口
```

> Windows 提示：本机未装 Node 时请先到 https://nodejs.org 安装；不要直接双击 index.html（联机模块加载不出来，页面会给出提示）。

## 本地双窗口联机测试

1. 启动服务后，打开两个浏览器窗口（或一台电脑 + 一台手机连同一局域网）都访问 `http://<本机IP>:3000`
2. 窗口 A 点「创建房间」，记下六位房间码
3. 窗口 B 输入房间码点「加入」，双方倒计时后自动开赛
4. 互相跳跃，观察对方小球的同步；收集星尘看双方计数；关掉一个窗口，另一窗口会出现「好友已断线」并在对方彻底离开后结算

## 部署方式一：腾讯云 CloudBase 云托管（国内推荐）

前置：已开通腾讯云 CloudBase 环境的「云托管」功能（控制台 → 云开发 → 环境 → 云托管 → 开通，免费）。

```bash
npm i -g @cloudbase/cli     # 安装 CLI
tcb login                   # 浏览器授权登录
tcb cloudrun deploy \
  --env-id <你的环境ID> \
  --service-name particle-run \
  --source . --port 80 \
  --min-num 1 --max-num 2 \
  --open-access-types PUBLIC --wait --force
```

部署完成后用 `tcb cloudrun detail --env-id <环境ID> --service-name particle-run --json` 查看 `DefaultDomainName` 即为公网地址。

> 计费说明：开通免费，运行按量计费（本项目 1 核 2G × 最少 1 副本）。不玩时可在控制台把最小副本数调为 0 自动缩容省钱。

## 部署方式二：Render 等海外平台（免费）

1. 把本仓库推送到 GitHub
2. Render 控制台 → New → Web Service → 连接该仓库
3. 配置：**Build Command**: `npm install`，**Start Command**: `npm start`
4. 部署完成后获得公开网址发给好友即可

其他任何支持 Node.js 的平台（Railway、Fly.io 等）同理：`npm install && npm start`，服务监听平台注入的 `PORT` 并绑定 `0.0.0.0`。

> 注意：Render 等海外平台在国内网络下可能无法访问或不稳定；免费实例会休眠，首次访问需等约 30–60 秒冷启动。

## 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| 页面显示「无法进入梦境 / 联机模块加载失败」 | 直接用 file:// 打开了文件。请 `npm start` 后访问 http://localhost:3000 |
| 提示「房间不存在」 | 房间码输错，或房主已退出/房间已被清理（无人房间即时销毁） |
| 提示「房间已满」 | 每房最多 2 人，请另建房间 |
| 提示「该房间正在进行比赛」 | 等当前局结束后再加入 |
| 好友刷新后不见了 | 8 秒宽限期内刷新会自动恢复；超过 8 秒会判定离开并提前结算 |
| 部署后打不开 | 查看平台日志；确认 Dockerfile / 启动命令正确、容器端口与 PORT 一致 |
| 免费部署第一次很慢 | 平台休眠冷启动，等待即可 |
